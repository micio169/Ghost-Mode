# 👻 GHOST MODE
> **Riot Game Offline Status Tool**

> **Just Open Source Project**

라이엇 게임사의 게임(리그 오브 레전드, 발로란트등) 플레이 중 방해받지 않고 싶을 때, 클릭 한 번으로 채팅 서버만 차단하여 '오프라인' 상태로 만들어주는 심플한 유틸리티입니다.

## ✨ 주요 기능
- **간편한 토글:** 클릭 한 번으로 온라인/고스트 모드 즉시 전환
- **안정적인 시스템:** 윈도우 방화벽(`netsh`) 기반의 확실한 차단 및 쿨타임 시스템
- **모던 디자인:** 세련된 다크 테마 UI 적용
- **실시간 감지:** 롤, 발로란트 클라이언트 실행 여부를 하단 바에서 실시간 확인
- **라이엇 게임 지원:** 롤에서 사용가능 / 발로란트에서 사용가능 (간단한 클릭으로 게임 변경가능)

## 🚀 시작하기
1. [Releases](https://github.com/micio169/Ghost-Mode/releases/tag/v1.1.0) 페이지에서 `GhostMode_Setup_v1.1.0.exe
`를 다운로드합니다.
2. 프로그램을 **관리자 권한**으로 실행합니다.
3. 버튼을 눌러 모드를 전환하세요. (반영까지 약 10~30초 소요)

## ➕ 추가 사항 (Notice)
- 테스트 결과 한국 서버 말고 다른 서버에서도 **사용 가능합니다.**
- V1.1.0에서 이젠 공식적으로 발로란트에서도 지원합니다.
- 리그 오브 레전드에서 **채팅 서버의 연결이 끊어졌습니다.** 같은 문구가 나온다면 **적용 완료된 것입니다.**
- 발로란트에서 **대기실에서 자신의 닉네임이 보이지 않거나 채팅을 칠 수 없다면** **적용 완료된 것입니다.**
